# Güvenlik / Security

Güvenlik açığı bulduysan lütfen herkese açık kayıt açma. Konu satırına
"Güvenlik" yazarak [info@noyku.com](mailto:info@noyku.com) adresine gönder.
Açığı nasıl tekrar edebileceğimi anlatman yeterli. En kısa sürede dönerim.

If you found a security issue, please do not open a public issue. Email
[info@noyku.com](mailto:info@noyku.com) with "Security" in the subject line
and describe how to reproduce it. I will get back to you as soon as I can.
